One-line comments only, informal tone. No multi-line or block comments.
No emojis anywhere — code, docs, commit messages, markdown.
Commit messages: single short line.
Branding: `authors = ["Felipe Carvajal Brown"]` in Cargo.toml (no "Software" suffix).
Fixes: root cause only — no test workarounds, no suppression.

**Why:** stated personal conventions across all projects.
**How to apply:** every file edit, every commit, every comment written in any project.
